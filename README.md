# Kirthik Portfolio

Premium data engineering portfolio site built with React, Vite, Tailwind CSS, and Framer Motion.

## Focus

The site is intentionally positioned for data engineering roles. It highlights:

- production-minded ETL and ELT work
- warehouse and lakehouse projects
- data quality and orchestration capabilities
- honest, limited AI usage as a supporting differentiator

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
